Supabase PostgreSQL एवं स्टोरेज विन्यास

यह वेबसाइट Supabase PostgreSQL, Supabase Auth एवं Supabase Storage के लिए पूर्ण रूप से तैयार है। वर्तमान में यह सुरक्षित स्थानीय स्टोरेज मोड में सभी प्रॉपर्टीज और पूछताछ को तुरंत सेव कर रही है।

डेटाबेस तालिकाओं की संरचना (Tables Included):

  • properties: आईडी, शीर्षक, प्रकार, क्षेत्रफल, कीमत, इलाका, सुविधाएं, स्थिति, फोटो एरे, टाइमस्टैम्प
  • buyer_enquiries: आईडी, नाम, फ़ोन, पसंदीदा प्रकार, बजट, संदेश, स्थिति, आंतरिक नोट्स
  • seller_enquiries: आईडी, मालिक नाम, फ़ोन, प्रकार, स्थान, माप, अपेक्षित मूल्य, फोटो, स्थिति
विस्तृत SQL स्कीमा फ़ाइल supabase/schema.sql और supabase/storage-rules.sql में उपलब्ध कराई गई है।
